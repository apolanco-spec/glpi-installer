# GLPI Installer

## Instalación
wget -O install-glpi.sh https://raw.githubusercontent.com/usuario/repo/main/install-glpi.sh
chmod +x install-glpi.sh
sudo ./install-glpi.sh

## Desinstalación
wget -O uninstall-glpi.sh https://raw.githubusercontent.com/usuario/repo/main/uninstall-glpi.sh
chmod +x uninstall-glpi.sh
sudo ./uninstall-glpi.sh
